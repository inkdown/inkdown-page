# Getting Started with Inkdown

Welcome to Inkdown! This guide will help you get started with our modern markdown editor.

## What is Inkdown?

Inkdown is a powerful, extensible markdown editor designed for your workflow. Whether you're writing documentation, taking notes, or creating content, Inkdown provides a seamless experience with:

- **Real-time Preview** - See your markdown rendered as you type
- **Plugin System** - Extend functionality with custom plugins
- **Theme Support** - Customize the look and feel
- **Cross-Platform Sync** - Access your notes anywhere

## Installation

### Desktop Application

Download the latest version for your platform:

```bash
# macOS
brew install inkdown

# Windows
winget install inkdown

# Linux
sudo snap install inkdown
```

### First Launch

When you first open Inkdown, you'll see:

1. **Welcome Screen** - Quick introduction to key features
2. **Workspace Setup** - Choose or create your workspace folder
3. **Tutorial** - Optional guided tour

## Quick Start

### Creating Your First Note

```typescript
// Create a new note
const note = await inkdown.createNote({
  title: "My First Note",
  content: "# Hello, Inkdown!\n\nThis is my first note."
});
```

### Basic Markdown Syntax

Inkdown supports all standard markdown syntax:

- **Bold** with `**text**`
- *Italic* with `*text*`
- `Code` with backticks
- [Links](https://inkdown.dev)
- Lists and more!
